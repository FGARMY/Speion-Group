# User Flows

## 1. User Onboarding
1. User signs up
2. Email verification
3. Create business profile
4. Land on dashboard

---

## 2. Create Website System
1. User visits website
2. Clicks "Start Project" / submits inquiry
3. Speion receives lead
4. You contact client (call / WhatsApp / email)
5. You understand:
   - Business type
   - Products
   - Target market
   - Requirements
6. You internally create project (Admin side)
7. You design + build website/system
8. Share preview with client
9. Revisions (if needed)
10. Final delivery + deploy
11. Optional: Add to system (future automation / CRM)

---

## 3. Lead Capture Flow
1. Buyer visits website
2. Submits inquiry form
3. Lead stored in DB
4. Notification sent to business
5. Lead appears in dashboard

---

## 4. Lead Management
1. User opens dashboard
2. Views leads list
3. Changes status (new → contacted → converted)
4. Adds notes (future feature)

---

## 5. Automation Flow
1. User creates automation rule
2. Trigger = form submission
3. Action = send email / webhook
4. System executes automatically

---

## 6. Subscription Flow
1. User selects plan
2. Payment via RevenueCat/Stripe
3. Subscription activated
4. Features unlocked

---

## 7. Admin Flow
1. Admin logs in
2. Views all users/projects
3. Manages subscriptions
4. Monitors system health
